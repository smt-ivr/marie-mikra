# מארי מקרא — ממשק ניהול

ממשק ניהול למערכת "מארי מקרא" על גבי ימות המשיח.
פיתוח מיוחד עבור ת"ת בת עין צפת · פותח בסייעתא דישמיא ע"י שימי טרייטל.

## מה יש כאן

| נתיב באתר | מה זה | איפה בקוד |
|---|---|---|
| `/` | **הגרסה החדשה** | `public/index.html`, `public/assets/` |
| `/legacy/` | **הגרסה הישנה, בלי שום שינוי** | `public/legacy/` |

בכל מסך בגרסה החדשה יש כפתור **"לגרסה הישנה"**: בסרגל העליון, בתפריט הצד ובמסך הכניסה.
שתי הגרסאות שומרות את ההגדרות באותו מקום בדפדפן, לכן מעבר ביניהן לא מנתק את החיבור.

> בגרסה הישנה הוסרו רק שני קטעים שלא היו חלק מהקוד: הערה ש-Netlify מוסיף לדף, וסקריפטים ש-NetFree הזריק בזמן ההורדה.
> הקובץ `smt.png` (הלוגו) לא היה בקובץ ה-zip. כדי שיופיע בגרסה הישנה, יש להעלות אותו ל-`public/legacy/smt.png`.

## מה חדש בגרסה החדשה

- **עריכת ציון של תלמיד במבחן**, גם במבחן הפעיל וגם במבחנים קודמים:
  - קודם קוראים את הקובץ מחדש מהשרת, ומשנים רק את הציון של אותו תלמיד. כל שאר הקובץ נשאר בדיוק כפי שהיה.
  - אחרי השמירה בודקים מול השרת שהשינוי נשמר באמת.
  - אם יש תלמידים בתוך שלוחת המבחן ברגע השמירה, מופיעה אזהרה.
  - יש יומן שינויים עם אפשרות **לבטל שינוי**. היומן נשמר בדפדפן שבו בוצעה העריכה.
- לוח סקירה כללית: המבחן הפעיל, סטטוס חסימה, זמני כניסה, נקודות, תלמידים, שיחות פעילות ויתרת יחידות.
- דוח מבחן עם סטטיסטיקה (ממוצע, חציון, התפלגות ציונים), ניתוח אחוז הצלחה בכל שאלה, חיפוש, מיון, ייצוא ל-Excel והדפסה.
- כל היכולות של הגרסה הישנה:
  - מבחנים: סגירת מבחן לארכיון, חסימה ופתיחה, הצגת שאלות, ייבוא שאלות, מחיקה לצורך מבחן חוזר.
  - נקודות, תלמידים, זמנים, צינתוקים, לוגים, אימות דו-שלבי ושיחות בזמן אמת.
- מצב כהה, ותצוגה מותאמת לטלפון.
- אבטחה: הודעות המערכת מוצגות במסגרת מבודדת, שאין לה גישה לטוקן ולסיסמה.

## העלאה ל-Cloudflare

האתר סטטי לגמרי, ואין שלב בנייה. כל הקבצים שמוגשים נמצאים בתיקייה `public/`.

**אפשרות א' — Workers (הדרך המומלצת היום אצל Cloudflare):**
1. בלוח הבקרה של Cloudflare נכנסים ל-**Workers & Pages**, ובוחרים **Create** ואז **Import a repository**.
2. בוחרים את המאגר `marie-mikra` ואת הענף הרצוי.
3. את פקודת הבנייה משאירים ריקה. פקודת הפריסה היא `npx wrangler deploy`, והיא קוראת את `wrangler.jsonc`.
4. מכאן, כל דחיפה לענף מעלה גרסה חדשה אוטומטית.

**אפשרות ב' — Pages:**
1. נכנסים ל-**Workers & Pages**, ובוחרים **Create** ואז **Pages** ואז **Connect to Git**.
2. Framework preset: `None`. את Build command משאירים ריק. Build output directory: `public`.

**דומיין משלכם:** בהגדרות הפרויקט ב-Cloudflare בוחרים **Custom domains** ומוסיפים את הדומיין.

אחרי שהאתר עובד ב-Cloudflare אפשר למחוק את האתר ב-Netlify.
שימו לב: ההגדרות השמורות בדפדפן (מספר מערכת, סיסמה, נתיבים) שייכות לכתובת האתר. בכתובת החדשה צריך להתחבר פעם אחת מחדש.
אפשר גם קישור עם פרמטרים, כמו בגרסה הישנה: `?username=...&password=...` או `?token=...`.

## הרצה מקומית

```bash
cd public && python3 -m http.server 8080
```

ואז לפתוח בדפדפן את `http://localhost:8080`.

## מבנה הקוד

```
public/
  index.html               דף הגרסה החדשה
  message-frame.html       מסגרת מבודדת להודעת המערכת
  _headers                 כותרות אבטחה (Cloudflare)
  assets/css/app.css       עיצוב
  assets/js/main.js        מסגרת האפליקציה, מסך כניסה וניווט
  assets/js/core/          חיבור ל-API של ימות, התחברות, רכיבי ממשק, עבודה עם קבצי ymgr
  assets/js/views/         המסכים: סקירה, מבחנים, נקודות, תלמידים, זמנים, צינתוקים, לוגים, הגדרות
  assets/js/widgets/       אימות דו-שלבי, שיחות פעילות, הודעת מערכת
  legacy/                  הגרסה הישנה, ללא שינוי
wrangler.jsonc             הגדרות פריסה ל-Cloudflare
```
