# מארי מקרא

ממשק ניהול למערכת "מארי מקרא", פרוס כ-Cloudflare Worker. בנוי באותו מבנה כמו "מסכת של שבת".
פיתוח מיוחד עבור ת"ת בת עין צפת · פותח בסייעתא דישמיא ע"י שימי טרייטל.

## מבנה

- `public/` – האתר המקורי (העיצוב בדיוק כמו שהיה), מוגש ב-`/marie-mikra/`
- `public/new/` – הממשק החדש, מוגש ב-`/marie-mikra/new/`
- `public/admin.html` – דף הניהול, מוגש ב-`/marie-mikra/admin`
- `src/worker.js` – ה-Worker שמגיש את כל הקבצים לפי הנתיב
- `src/api/` – השרת: כניסה, משתמשים והרשאות, יומנים, ושער למערכת (מסד D1 `tfila`, טבלאות `mm_`)
- `wrangler.jsonc` – הגדרות הפריסה ל-Cloudflare

## נתיבים

| כתובת | מה מוגש |
|-------|---------|
| `/marie-mikra/` | האתר המקורי, עם מסך כניסה |
| `/marie-mikra/new/` | הממשק החדש (למשתמש עם ההרשאה "ממשק חדש") |
| `/marie-mikra/admin` | ניהול (מנהל בלבד): משתמשים, הגדרות, יומן כניסות, יומן פעולות |
| `/marie-mikra/api/...` | כניסה, ניהול, ופניות למערכת דרך השרת (`src/api`) |
| `/marie-mikra/api/message` | שירות הודעת המערכת הקיים – עובר הלאה בלי שינוי |

`/marie-mikra` ו-`/marie-mikra/new` ללא `/` בסוף מופנים אוטומטית לנתיב עם `/`,
כדי שהקישורים היחסיים (CSS/JS/תמונות) ייטענו נכון.
הכתובת הקודמת `/marie-mikra/legacy/` מפנה לאתר הראשי.

## כניסה ומשתמשים (כמו במסכת של שבת)

**מסך הכניסה:**
- כניסה עם סיסמה בלבד, או אוטומטית מכתובת IP מורשית, או עם Google (אם הופעל בהגדרות).
- החיבור נשמר בעוגייה מאובטחת ל-30 יום.

**הגדרה ראשונית:** כשאין עדיין אף משתמש, מסך הכניסה מבקש פעם אחת טוקן וסיסמת מנהל.

**משתמשים:**
- לכל משתמש יש שם ומייל, ובתוכם סיסמה, כתובות IP והרשאות.
- המשתמשים נערכים בדף הניהול, ומשם אפשר גם לשלוח מייל פתיחה עם פרטי הכניסה.

**הרשאות:**
- לכל תחום יש צפייה או עריכה: מבחנים, נקודות, תלמידים, זמנים, צינתוקים, לוגים.
- בנוסף יש "ממשק חדש" ו"ניהול המערכת".
- מה שאין עליו הרשאה מוסתר באתר, והשרת חוסם אותו בכל מקרה.

**הטוקן ונתיבי הקבצים:**
- כל הפניות למערכת עוברות דרך השרת (`/marie-mikra/api/yemot/...`).
- הטוקן שמור במסד (`mm_settings`) ונערך בדף הניהול. הוא לא נשמר בדפדפן ולא במשתני סביבה.
- גם הכתובות במערכת נערכות בהגדרות הניהול. השרת מרשה גישה רק אליהן, וכל כתובת אחרת נחסמת.

**יומנים:**
- כל פעולה נרשמת ביומן הפעולות, וכל ניסיון כניסה נרשם ביומן הכניסות.
- טוקן או סיסמה שנשמרו בדפדפן בעבר נמחקים בכניסה, והמחיקה מדווחת ליומן.

## האתר המקורי

העיצוב לא שונה. כמו ב"מסכת של שבת", השינויים הם בקוד בלבד:
- **פניות דרך השרת:** `js/auth.js` ו-`js/mfa-controller.js` פונים לשרת במקום ישירות למערכת, והשרת מוסיף את הטוקן.
- **טעינה אחרי כניסה:** `js/script.js` נטען רק אחרי הכניסה, ונפתח בלשונית הראשונה שיש עליה הרשאה.
- **מסך הכניסה:** `index.html` כולל את מסך הכניסה (`css/login.css`, `js/session.js`).
- **פס משתמש:** בפינה צף פס קטן עם שם המשתמש, מעבר לממשק החדש, ניהול ויציאה.

## מסד נתונים

הנתונים נשמרים במסד D1 הקיים `tfila`, בטבלאות שמתחילות ב-`mm_` בלבד:
`mm_accounts`, `mm_user_ips`, `mm_sessions`, `mm_login_log`, `mm_action_log`, `mm_settings`, `mm_grade_history`, `mm_schema_migrations`.

- הטבלאות נוצרות אוטומטית בבקשה הראשונה (`src/api/schema.js`).
- שאר הטבלאות במסד לא נגעו.

## פריסה

Cloudflare מעלה כל שינוי בענף `main` אוטומטית. ידנית:

```bash
npx wrangler deploy
```

הדומיין מחובר ב-Cloudflare דרך Workers Routes, עם הנתיב `smti.uk/marie-mikra*`.
